下面这份 DMIT购买教程，按当前官网页面重新核过价格、库存、网络说明和购买后的 SSH 流程。本文价格以本次核验时官网公开页面为准；DMIT 自己也提醒，价格和产品库存可能因为调整出现更新滞后，所以真正付款前还是要以结算页显示为准。

## 先确定：你为什么要买 DMIT

DMIT 现在的 Cloud Instance 本质上是高性能 KVM 云实例。官网公开的硬件平台包括 AMD EPYC 9005 系列的 AN5、AMD EPYC 9004 系列的 AN4，以及 AMD EPYC 7003 系列的 AS3；其中 AN5 使用 Zen 5、DDR5 和 PCIe 5.0 NVMe，AN4 是 Zen 4，AS3 是 Zen 3。

线路则比 CPU 型号更值得先看。

**Premium Network** 使用包括 China Telecom CN2 GIA 在内的高级线路，官网把它定位为面向中国大陆和亚太访问体验的高规格网络；洛杉矶页面同时强调了其与中国电信、中国联通、中国移动国际的专用互联。

**Eyeball Network** 更偏成本与覆盖之间的折中。在洛杉矶，官网将其描述为通过 CMIN2 等线路改善中国住宅用户访问；香港的 Eyeball 当前仍处于 Beta，官方明确提示线路和表现仍在调优，不建议把它当成对高稳定性要求很高的生产环境首选。

**Tier 1 Network** 则是不专门针对中国大陆优化的国际线路，适合全球业务、备份、批量传输、CI/CD 和对中国方向优化要求没那么高的工作负载。

所以，DMIT购买教程最重要的一条其实很简单：

> **先选网络，再选机房和配置，不要反过来只看“几个核心、几 GB 内存”。**

## DMIT 到底应该怎么选

对于第一次买的人，不需要把 40 多个配置全部研究一遍。

### 面向中国大陆用户：先看网络，再看地区

如果服务主要给中国大陆访问，Premium 与 Eyeball 的区别应该放在配置前面考虑。

洛杉矶的 Premium 官方定位就是中国大陆和亚太优化线路；香港则同时有 CN2 GIA 与 CMI 优化，官方给出的香港到中国大陆参考平均延迟约 15ms，但实际效果依然跟用户所在地区和接入运营商有关。

香港的优势是物理距离更近，但价格也明显高。以当前页面的 Premium 套餐看，香港从 **$149.90/月** 起，而洛杉矶当前部分 Premium 配置从 **$10.90/月** 起。这里不能简单理解成“香港贵很多所以不值得”，因为二者对应的线路、带宽、套餐体系和硬件并不是完全相同。

### 预算优先：Tier 1 的价格非常低

如果你的业务并不依赖中国大陆方向的专门优化，Tier 1 反而值得认真看。

LAX、HKG 和 TYO 都有 Tier 1 方案，其中多个入门档只有 **$6.90/月**，部分 WEE 甚至直接按 **$36.90/年** 展示。对于开发测试、备份、中继、CI/CD 或纯国际业务，这类价格与高阶 Premium 不在一个成本区间。

但不能因为价格便宜，就默认 Tier 1 和 Premium “只是带宽不同”。DMIT 官方对两类网络的定位本身就不同：Premium 强调中国大陆方向优化，而 Tier 1 强调全球和亚太国际连接。

### 第一步：进入 DMIT 并注册账号

你提供的 AFF 链接实际会跳转到 DMIT 官方主页，当前官网顶部提供 `Sign Up` 和 `Sign In`。

👉 [进入 DMIT 购买入口](https://bit.ly/DmiT)

注册时按页面要求填写账号信息即可。这里没有必要去找第三方“特殊注册链接”，因为你已经有经过验证的联盟入口。

注册成功后进入客户中心，下一步就是选 VPS。

### 第二步：先选机房

可以把选择逻辑压缩成三个问题：

**访问者主要在中国大陆？** 看香港或洛杉矶的 Premium。

**需要日本机房或日韩方向较近的节点？** 看 Tokyo。

**主要是欧美、亚太全球业务，不特别依赖中国优化？** Tier 1 先看起来。

DMIT 当前只公开展示 Los Angeles、Hong Kong、Tokyo 三个 Cloud Instance 节点。

### 第三步：再选网络系列

这一步比“2 核还是 4 核”更重要。

Premium：偏中国大陆和亚太访问质量。

Eyeball：成本和中国住宅用户访问之间的折中，但香港 Eyeball 当前仍然是 Beta。

Tier 1：偏国际网络与价格，适用于不需要专门中国线路优化的工作负载。

### 第四步：最后才挑 CPU、内存和流量

例如一个简单的网站、开发环境或者反向代理，并不一定需要 8 vCore + 16GB RAM。

反过来，如果要跑数据库、多人并发应用、构建任务或者较重的业务，低配套餐的省钱通常只是把成本延后到升级上。

LAX AN5 官网把它定位为最高性能平台，AN4 偏均衡，AS3 则强调成本效益；这比单纯拿“核心数”做选择更有参考意义。

## 付款前一定看这几个地方

### 计费周期

当前价格页公开展示的绝大部分套餐是月付，但个别 Tier 1 WEE 直接展示年付价格。不要看到 `$36.90` 就以为是月费，也不要看到 `$6.90` 就误认为是年付。官网实际上同时存在月付和年付两种展示。

### Promo Code 不要照抄旧教程

这一点尤其容易踩坑。

搜索结果里仍然能看到不少 2026 年旧文章，把之前的价格和优惠码直接贴出来。例如一些购买教程使用过 `$49.9/年`、`$88.88/年` 等旧数字，但它们与当前官网公开 Pricing 页面已经不一致。

本次核验没有从 DMIT 官网确认一个可以放心写死在文章里的**通用当前优惠码**。所以更稳妥的操作是：结算时看到 `Promo Code` 输入框，再验证你手上的代码是否真的适用于当前套餐和计费周期，而不是因为某篇几个月前的教程写过就直接付款。

### PayPal 或信用卡支付失败怎么办

DMIT 官方账单 FAQ 明确提到，PayPal 和信用卡支付需要完整的个人与地址信息；PayPal 未验证、信用卡不支持 3D Secure，以及 Stripe 风控拦截，都可能造成付款失败。

所以付款失败时，先检查资料完整性和支付方式，不要连续重复提交几十次订单。

DMIT 的退款文档则明确涉及 Alipay 的退款规则，因此结账页面如果为你的账户提供 Alipay，可以按照页面提供的支付方式完成付款。

## 买完之后最容易踩的坑：SSH

DMIT 当前默认不允许通过远程 Root 密码直接登录，这是购买后最容易让新手误以为“服务器没开”的地方。

官方实例 FAQ 明确说明，远程 Root 密码登录默认被禁用，推荐通过 SSH Key 登录。

购买实例时，可以选择让系统自动生成 SSH Key。之后在实例的 `Access` 页面下载密钥，压缩包里会包含 `.pem` 私钥、`.pub` 公钥以及用于 PuTTY 的 `.ppk` 私钥格式。

这一点真的要认真记住：

> **私钥丢了，不是“再发一封邮件给客服就找回原文件”。**

DMIT 官方文档说明，如果私钥丢失，可以在实例控制面板重新更换密钥；同时官方明确提醒不要泄露私钥。

Windows 用户可以用 XShell、PuTTY 等 SSH 客户端；DMIT 当前文档给出的默认 SSH 端口是 `22`，默认用户名通常是 `root`。

Mac 或 Linux 更直接，拿到私钥之后，基本就是：

bash
chmod 600 your-key.pem
ssh -i your-key.pem root@你的服务器IP


这里的关键不是命令有多复杂，而是**确认私钥、IP 和用户名对应同一台实例**。

## 流量用完会发生什么？

这个问题买之前就应该看。

DMIT 当前文档把传输额度处理分成不同模式。部分实例采用双向计费，也就是上传和下载都计入；另一类采用“单向最大值”方式，两边流量取较大值计算。超出流量之后，还可能触发暂停、限速或者不限制三种不同处理方式，具体取决于实例本身的计费模型。

因此，不要只看“5000GB”这个数字。

**5000GB 双向计费**和**5000GB 单向最大值计费**对高上传业务的实际可用量不是同一个概念。

对于文件分发、备份、下载站、视频、镜像或大量跨境数据传输，流量计算方式甚至比多 1 个 vCPU 更值得研究。

## IP 也别想当然

DMIT 官方文档明确说明，分配到的 IP 地址是系统随机分配的，不能指定某个具体 IP 段或特定 IP；IP 本身也不保证具备某个地区的地理信息，更不保证能够访问某个网站或服务。

这意味着购买 VPS 时，不应该把“香港 VPS”“东京 VPS”理解成“这个 IP 对所有网站都会显示成你想要的地区”。

另外，DMIT 目前大多数实例不支持增加额外 IPv4，官方明确列出的例外是 LAX Pro 系列支持额外 IP，但仍需要提交工单处理。

## 退款前需要注意什么

DMIT 当前退款文档特别提醒：发起退款后，实例会被停止，以避免继续消耗传输额度；退款确认后实例数据会被删除且无法恢复，所以要在提交退款之前做好备份。

退款到原始支付方式时，可能会扣除支付机构收取的相关费用；退款到 DMIT 余额则没有这一类支付提供商手续费。对于 Alipay，官方文档特别说明退款时支付手续费会返还，因此不收退款手续费。

所以不要把“先随便买一个试试”理解成完全没有成本的试用。
